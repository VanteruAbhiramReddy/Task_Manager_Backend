# Task Manager Backend

A backend REST API built with Node.js, Express, and PostgreSQL.

Current progress includes:

- User signup and login
- Password hashing and verification
- Session-based authentication
- Express middleware architecture
- PostgreSQL session persistence
- Protected routes using auth middleware
- CRUD operations for tasks
- Task ownership authorization
- Centralized async error handling
- Validation middleware using Zod
- PostgreSQL relational database integration

## Tech Stack

- Node.js
- Express.js
- PostgreSQL
- express-session
- connect-pg-simple
- Zod

This project was built primarily to deeply understand backend architecture, authentication systems, middleware lifecycles, and database-driven application design.
